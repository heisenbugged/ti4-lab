# Verifying TI4 Lab

## Launch

- Dev server: `TI4_LAB_DATABASE_PATH=file:///Users/jstrong/webapps/ti4-lab/sqlite.db npm run dev` (port 3000, hardcoded in server.ts). The DB path must be a `file://` URL — a bare path (absolute or relative) crashes `config.server.ts` with ERR_INVALID_URL.
- A dev server is often already running on :3000 with Vite HMR — check `lsof -nP -iTCP:3000 -sTCP:LISTEN` first and just reuse it; file edits hot-reload.

## Drive / capture

- No playwright in this repo. The `~/Library/Caches/ms-playwright/` cache may be empty; system Chrome at `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` works as `executablePath` with `playwright-core` installed in the scratchpad.
  - Quick screenshots: `~/Library/Caches/ms-playwright/chromium_headless_shell-*/chrome-headless-shell-mac-arm64/chrome-headless-shell --headless --disable-gpu --screenshot=out.png --window-size=1440,1300 --hide-scrollbars --virtual-time-budget=8000 <url>`
  - Interaction: `npm install playwright-core` in the scratchpad, launch with `executablePath` pointing at `~/Library/Caches/ms-playwright/chromium-*/chrome-mac-arm64/Google Chrome for Testing.app/Contents/MacOS/Google Chrome for Testing`.

## Gotchas

- Driving like buttons writes real rows to `sqlite.db` (`presetMapLikes` + `presetMaps.likes`); clean up after (dev likes land with ip `unknown`).
- better-sqlite3: drizzle transactions must be synchronous (`db.transaction((tx) => ...)` with `.all()/.run()`); async callbacks throw at runtime only — typecheck won't catch it.
- Known pre-existing hydration warning: nested `<a>` from the Generator button inside map card links.
- `yarn typecheck` (plain `tsc`) is clean; `src/routeTree.gen.ts` is regenerated by the TanStack Start Vite plugin (dev server or `vite build`) — commit it with route changes.
- Creating drafts queues image jobs that upload to the real R2 bucket when `.env` has R2 creds; pass `R2_INTEGRATION_DISABLED=true` when driving draft creation.
- Production check: `vite build`, then `NODE_ENV=production PORT=<free> tsx server.ts` serves `dist/` (Express + socket.io wrap Start's fetch handler). Vite's dev server rejects unknown Host headers, so test host-based redirects against the prod build.
